# wag / PICOPET

반려견의 심박수 측정 기기와 Flutter 앱을 연결한 팀 프로젝트입니다. 한남대학교 IPD 수업에서 TJB 기업 연계 프로젝트로 진행했으며 전시회에 출품했습니다.

## 주요 기능

- 반려견 정보 등록과 확인
- 측정 기기와 앱의 BLE 연결
- 심박수 데이터 수신과 화면 시각화

## 구현 방식

Arduino 기반 심박수 측정 기기와 Flutter 앱 개발을 담당했습니다. 센서에서 수집한 측정값을 BLE로 앱에 전달하고 Flutter 화면에 표시했습니다.

기기와 앱이 연결되는 흐름을 구현하고, 보호자가 반려견의 심박수 변화를 확인할 수 있도록 화면을 구성했습니다.

## 사용 기술

Flutter, Dart, Arduino, Bluetooth LE
