# 안전 도보 내비게이션

범죄 위험 구역을 확인하고 회피하는 도보 내비게이션입니다. 한남대학교 컴퓨터공학과 졸업작품으로 진행한 팀 프로젝트이며, Android UI/UX 설계·개발과 Tmap API 연동을 담당했습니다. 2024년 컴퓨터공학과 학술제에서 최우수상을 수상했습니다.

## 주요 기능

- 현재 위치 확인과 지도 표시
- 출발지·목적지 입력 및 장소 검색
- 보행 경로 조회와 지도 표시
- 경로 거리·소요 시간 확인
- 범죄 위험 구역을 고려한 도보 이동 안내

## 구현 방식

Java로 Android 화면을 개발하고 XML Layout과 View Binding으로 화면 요소를 연결했습니다. Tmap SDK·API를 이용해 지도와 검색 결과를 표시하고 보행 경로를 조회했습니다.

Android Location API로 현재 위치를 받아 지도에 반영했습니다. 출발지·목적지 검색 결과는 목록으로 제공하고 선택한 위치를 경로 조회에 사용했습니다. 조회된 경로는 지도 위 선과 거리·소요 시간으로 표시했습니다.

위험 구역을 고려하는 서비스는 팀 단위로 개발했으며, 제가 담당한 부분은 Android 화면과 지도·경로 API 연동입니다.

## 사용 기술

Android, Java, XML Layout, View Binding, Tmap SDK·API, Android Location API
