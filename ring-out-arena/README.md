# Ring Out Arena

상대를 발판 밖으로 밀어내는 브라우저 대전 게임입니다. TypeScript와 Matter.js로 게임 진행과 물리 처리를 구현하고 Canvas로 화면을 그렸습니다.

## 주요 기능

- AI를 상대하는 캠페인과 같은 화면에서 진행하는 2인 대전
- 이동·점프·대시와 충돌에 따른 밀어내기
- 링아웃·동시 탈락·제한 시간 종료에 따른 승패 판정
- 스테이지와 레벨별 난이도, 진행 상황 저장
- 키보드·모바일 터치 조작과 화면 연출 줄이기
- 광고판과 리워드 광고 흐름의 모의 처리

## 구현 방식

게임 상태와 라운드 진행, 물리 월드, 캐릭터, 렌더링, 입력 처리를 나눴습니다. Matter.js로 충돌과 움직임을 처리하고 Canvas로 경기장과 캐릭터를 표시했습니다.

링아웃과 시간 초과 판정은 게임 루프와 분리했습니다. 제한 시간이 끝나면 스테이지 중앙과의 거리를 비교하고, 차이가 작으면 무승부로 처리했습니다.

광고 처리는 별도 인터페이스로 분리하고 개발용 모의 구현을 연결했습니다. Vite로 개발·빌드 환경을 구성하고 GitHub Actions와 Pages 배포 설정을 작성했습니다.

## 사용 기술

TypeScript, Matter.js, HTML Canvas, Vite, GitHub Actions, GitHub Pages
