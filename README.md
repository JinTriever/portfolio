# 손영진 포트폴리오

Flutter·Dart를 중심으로 앱과 기기가 연결되는 기능을 개발해 왔습니다. 프로젝트별로 만든 기능과 구현 방식을 정리했습니다.

| 프로젝트 | 내용 |
|---|---|
| [WhisPet](whispet/) | 반려견 음악 IoT 제품의 앱·웹과 게이트웨이 연결 |
| [펫하루](petharu/) | 반려견의 외출·생활 기록과 분리불안 관리 앱 |
| [안전 도보 내비게이션](safe-walking-navigation/) | Tmap을 활용한 Android 도보 내비게이션 |
| [wag / PICOPET](wag/) | Arduino 측정 기기와 Flutter 앱의 BLE 연동 |
| [Ring Out Arena](ring-out-arena/) | TypeScript·Matter.js 기반 브라우저 대전 게임 |
| [Neubreze Workspace](workspace/) | Python·Swift 기반 개인용 macOS 작업공간 |
